iShopping

Planning the month's shopping within a budget, with a receipt at the end.

View the code ↗ (opens in a new tab)
Year
2026, 1st year of the CTeSP
Role
Team of 2, with Paulo
Status
Finished
Stack
C#, Entity Framework, SQL Server

The challenge

Help a family not spend more than they planned: set a budget for the month, make the list and know straight away whether it will go over.

What we built

  • A maximum budget per month.
  • A planned shopping list, with expected and unexpected items.
  • The running total, with a warning when the budget is exceeded.
  • A printed receipt at the end of the shop.
  • The family's shopping history and statistics.

How it works

A Windows Forms app in C#, organised into models, views and controllers. The database is created with Entity Framework Code First and migrations, on SQL Server LocalDB.

What I learned

Using an ORM and migrations instead of writing SQL by hand, and keeping the interface apart from the logic.
