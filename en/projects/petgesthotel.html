The challenge

A pet hotel has to manage rooms, bookings, extra services and communication with owners. The project brings it all into one system with a website, an API and a mobile app.

What we are building

  • Room and service bookings for the pet, with availability search by dates.
  • Four roles: visitor, client, staff and administrator.
  • One API serving both the website and the Android app.
  • In-app chat between the client and the hotel staff.

How it works

The website and the API are built with Yii2 Advanced, using migrations for the database and the framework's models, views and controllers. The Android app uses the same API.

Status

The home page is done, with the availability search. This page will be updated as the project moves forward.
