TelePomba

A browser chat with real-time messages, groups and file sharing.

View the code ↗ (opens in a new tab)
Year
2025, 12th grade
Role
Scrum master and lead, team of 6
Status
Class project
Stack
PHP, Node.js, Socket.IO, MySQL

The challenge

Build, as a class, a chat that worked live between different computers, with accounts, groups and files, like the apps we use every day.

What I built

  • Sign-up, sign-in, profile and password recovery by email.
  • One-to-one and group conversations, with user search to add people.
  • Messages delivered in real time and each person's online status.
  • Sharing images, videos and other files.
  • As scrum master and lead, I organised the team's tasks and integrated everyone's work. I made 44 of the 72 commits.

How it works

The pages and the API are PHP with MySQL. A Node.js server with Socket.IO delivers messages instantly and updates user status. To test across computers, we exposed the server with ngrok.

What I learned

How real-time connections work with WebSockets, and how to lead a team of six: splitting the work, following what everyone is doing and bringing it all together in one repository.
