Lux

An AI assistant that runs entirely on your own computer: it chats, reads files and codes inside a folder.

Talk about this project →

Role
Personal project, solo
Status
In daily use
Stack
Python, JavaScript, Ollama

The challenge

I wanted an assistant like Claude Code or Codex, but one that worked offline and never sent my files anywhere.

What I built

  • Two modes: plain chat, and coding inside a project folder.
  • In coding mode it reads, searches, writes and edits files and runs commands, always asking for permission first.
  • Image, PDF and text file attachments.
  • One-click setup that checks memory and the graphics card and recommends the right model.
  • Voice input with Whisper and, optionally, cloud models.

More screens

How it works

A Python server talks to Ollama, which runs the models on the computer. The interface is HTML, CSS and JavaScript and opens in its own window.

What I learned

How language models work inside an application: context, tools and memory limits.
