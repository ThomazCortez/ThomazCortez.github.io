SecureChat

A group chat where messages travel encrypted and signed.

The challenge

Build a chat where several people talk in the same room, in real time, without anyone listening on the network being able to read or change the messages.

What we built

  • A TCP server that accepts several clients at once.
  • Sign-up and sign-in, with passwords stored as salted hashes.
  • 2048-bit RSA key exchange and messages encrypted with AES.
  • Every message signed with SHA-256 and verified on the other side.
  • /users and /msg commands to see who is online and send private messages.
  • A colour of choice for each user.

More screens

How it works

Client and server in C#, talking over TCP with ProtocolSI. Users are stored in a SQL Server LocalDB database.

What I learned

The difference between encrypting, signing and hashing, and why each one solves a different problem.
