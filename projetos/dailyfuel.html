DailyFuel

Um diário privado de calorias, peso e água, com lembretes para beber água e treinar.

O desafio

Queria ganhar peso e não sabia se estava a comer o suficiente nem a beber água com regularidade. Precisava de ver tudo isso num só sítio, todos os dias, por isso fiz a minha própria app.

O que fiz

  • Diário de refeições com calorias e macronutrientes.
  • Registo de peso com gráfico de progresso.
  • Contador de água ao longo do dia.
  • Lembretes no telemóvel para beber água e treinar.
  • Treinos, hábitos e uma lista de tarefas.

Mais ecrãs

Como funciona

Next.js com TypeScript, exportado como site estático e alojado no Cloudflare Pages. O Supabase trata do início de sessão por email e guarda os dados de cada conta, com row-level security para que ninguém leia os dados de outra pessoa. As notificações chegam através do ntfy.

O que aprendi

TypeScript e React num projeto real, e como migrar os dados de uma versão antiga para uma base de dados nova sem perder nada.
