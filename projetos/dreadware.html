Dreadware

Um jogo de terror no Roblox: reparar computadores e fugir antes de o tempo acabar.

O desafio

Fazer um jogo de terror multijogador completo, sozinho: mapa, mecânicas, animações e interface.

O que fiz

  • Objetivo com tempo: reparar computadores para revelar o código de saída.
  • Mecânicas de fuga, como saltar e partir paletes, e de ajuda, como curar e carregar outro jogador.
  • Animações próprias para cada ação.
  • Interface com o contador de computadores, o código e o relógio.

Como funciona

O código é escrito em Luau e sincronizado com o Roblox Studio através do Rojo, o que me deixa usar Git e o meu editor. As animações são geradas com scripts em Python.

O que aprendi

A lógica de um jogo multijogador, em que o servidor decide e os clientes só mostram, e como organizar um projeto grande sozinho.

Em breve

O código e uma demonstração ficam disponíveis quando o projeto avançar.
