iShopping

Planear as compras do mês dentro de um orçamento, com recibo no fim.

Tecnologias
C#, Entity Framework, SQL Server

O desafio

Ajudar uma família a não gastar mais do que planeou: definir um orçamento para o mês, fazer a lista e saber logo se o vai ultrapassar.

O que fizemos

  • Orçamento máximo por mês.
  • Lista de compras planeada, com artigos previstos e não previstos.
  • Cálculo do total e aviso quando o orçamento é ultrapassado.
  • Recibo impresso no fim da compra.
  • Histórico de compras da família e estatísticas.

Como funciona

Aplicação Windows Forms em C#, organizada em models, views e controllers. A base de dados é criada com Entity Framework Code First e migrations, em SQL Server LocalDB.

O que aprendi

Usar um ORM e migrations em vez de escrever o SQL à mão, e separar a interface da lógica.
