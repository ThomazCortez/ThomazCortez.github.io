PetGestHotel

Um hotel para animais: reservas de quartos e serviços num site e numa app Android, ligados à mesma API.

O desafio

Um hotel para animais precisa de gerir quartos, reservas, serviços extra e a comunicação com os donos. O projeto junta tudo num sistema com site, API e app móvel.

O que vamos fazer

  • Reserva de quartos e serviços para o animal, com pesquisa de disponibilidade por datas.
  • Quatro perfis: visitante, cliente, colaborador e administrador.
  • Uma API que serve o site e a app Android.
  • Chat na app entre o cliente e os colaboradores do hotel.

Como funciona

O site e a API são feitos em Yii2 Advanced, com migrations para a base de dados e a estrutura de models, views e controllers da framework. A app Android consome a mesma API.

Estado

Já temos a página inicial, com a pesquisa de disponibilidade. Esta página vai ser atualizada à medida que o projeto avança.

Em breve

O código e uma demonstração ficam disponíveis quando o projeto avançar.
